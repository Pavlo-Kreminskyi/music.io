# Сайт Павла Кремінського

## Структура репозиторію для GitHub Pages

```
/
├── index.html        ← головний файл сайту (CSS і JS вбудовані всередині)
├── manifest.json      ← налаштування PWA (встановлення як застосунок)
├── sw.js               ← service worker (офлайн-кеш, потрібен для PWA)
├── images/
│   ├── logo.png        ← ваш логотип, 400×400 px (поки відсутній — показується "PK")
│   ├── song1.jpg        ← обкладинка першого треку
│   └── ...
└── songs/
    ├── song1.mp3         ← перший трек
    └── ...
```

## Як додати пісню

1. Файл `.mp3` → у папку `songs/`
2. Обкладинку (`.jpg`/`.png`) → у папку `images/`
3. Назви файлів — латиницею, без пробілів (`moya-pisnya.mp3`, не `моя пісня.mp3`)
4. Відкрийте `index.html`, знайдіть масив `const songs = [ ... ]` у секції
   `<script>`, скопіюйте закоментований "ШАБЛОН ДРУГОЇ ПІСНІ" і заповніть
   своїми даними.

## Як опублікувати на GitHub Pages

1. Завантажте всі файли й папки в репозиторій на GitHub.
2. Відкрийте Settings → Pages.
3. У розділі "Build and deployment" оберіть Source: `Deploy from a branch`,
   гілку `main` (або `master`), папку `/root`.
4. Збережіть — сайт зʼявиться за адресою
   `https://<ваш-нікнейм>.github.io/<назва-репозиторію>/`.
5. Встановлення як застосунок (PWA) запрацює автоматично, оскільки
   GitHub Pages роздає сайт по HTTPS.

## Розділення на окремі файли (опційно)

Зараз CSS і JS вбудовані прямо в `index.html` для зручного попереднього
перегляду одним файлом. Якщо хочете розділити проєкт:

1. Виріжте вміст тега `<style>...</style>` → вставте у новий файл
   `css/style.css`, а в `<head>` додайте:
   `<link rel="stylesheet" href="css/style.css">`
2. Виріжте вміст тега `<script>...</script>` (той, що з кодом застосунку,
   не PWA-реєстрацію окремо) → вставте у новий файл `js/app.js`, а перед
   `</body>` додайте: `<script src="js/app.js"></script>`

Усі шляхи в коді вже відносні, тому розділення нічого не зламає.
